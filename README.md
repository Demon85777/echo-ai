# ECHO AI OS

ECHO AI OS — расширяемая Python-основа для ИИ-приложений и автоматизированных процессов.

В основе проекта: события, сервисы, постоянная память, плагины и будущие интерфейсы для AI-движков и API.

## Быстрый старт

```bash
python3.11 -m pip install -e ".[dev]"
python -m echo_ai.cli emit boot --payload '{"source":"cli"}'
pytest
```
