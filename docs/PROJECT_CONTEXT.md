# Контекст ECHO AI OS

## Цель

Создать расширяемую платформу для ИИ-процессов, в которой память, движки,
плагины и внешние интерфейсы подключаются к небольшому, хорошо тестируемому ядру.

## Принципы

1. Явные небольшие интерфейсы.
2. Минимум зависимостей в ядре.
3. События как стабильная граница между модулями.
4. Память и AI-провайдеры подключаются через адаптеры.
5. Публичное поведение покрывается тестами.
