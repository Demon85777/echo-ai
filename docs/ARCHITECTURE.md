# Архитектура ECHO AI OS

```text
CLI / будущий API / Plugins
           |
        Runtime
      /        \
   Events      Memory
```

- **Event** — неизменяемый факт с темой и данными.
- **Runtime** доставляет события подписчикам темы и универсальным подписчикам.
- **JsonMemoryStore** сохраняет контекст локально в JSON.
- **CLI** — первый внешний интерфейс для публикации событий.

Следующие модули — плагины, конфигурация, AI-движки и REST API.
